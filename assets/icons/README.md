# CRM icon artwork

`crm-icons.css` bundles 40 selected SVGs from the official `lucide-static@1.61.0`
package as decorative CSS masks. Only the selected paths are included; no icon
font, remote script, JavaScript icon runtime or package dependency was added.

Source: https://www.npmjs.com/package/lucide-static/v/1.61.0
Project: https://lucide.dev/
License: [LICENSE](LICENSE), preserved from the package.
Package SHA-1: `ee7141b653f866e3222bd9d2b167b9e6d931ff10`.
Package integrity: `sha512-yLAiQB3MWUJEstsEDAwenSA3m7vr1tdLvgnC16Q/XMxRRma0DWwMs8M2bWlvgShrIs1m2mWMJ+0AiahqQO4GrA==`.

CSS-only decoration preserves button labels, accessible names, IDs, form types,
handlers and existing loading/recording label updates. Existing record cards and
buttons with SVGs keep their icon/layout implementation until their page pass.
Canonical icon names in this package include `funnel`, `trash` and `building`.
